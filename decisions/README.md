# Decision records

One file per gate run: `YYYY-MM-DD-<slug>.md`, from `skills/wait-answer/templates/decision-record.md`.

The point is not the advice — it is the follow-up. Each record carries a follow-up date three to four
weeks after the decision. When the skill next loads, it compares the predicted usage frequency with what
actually happened, and writes the outcome into the record.

That comparison is the only evidence that the gate is worth having. A record without a follow-up date is
decoration.
